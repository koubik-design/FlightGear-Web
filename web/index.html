Independent browser-port engineering project

FlightGear-Web

Exploring a real native C++ FlightGear / SimGear / OpenSceneGraph port to WebAssembly, using WebGL 2.0 and OpenGL ES 3.0.

Phase 1 · Toolchain bootstrap

Development status

The initial Emscripten, CMake and Docker toolchain is being established. The current build target is only a minimal compiler smoke test.

No playable simulator is available yet. FlightGear engine, scenery, aircraft, browser persistence, rendering and multiplayer integration are future milestones.
